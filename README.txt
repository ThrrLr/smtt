APPLICATION SMTT — PREMIÈRE MAQUETTE

Cette version est une base de départ pour GitHub Pages.
Les 7 rubriques demandées sont présentes :
Équipes / Vidéos / Facebook / WhatsApp / Calendrier / HelloAsso / Documents.

IMPORTANT :
- Le logo fourni ici est un logo provisoire SMTT en attendant de replacer le logo officiel du club.
- Les liens externes et les contenus réels ne sont pas encore configurés.
- Cette application est une PWA : elle pourra être ajoutée à l'écran d'accueil d'un iPhone depuis Safari.
- Hébergement prévu : GitHub Pages (gratuit pour ce site statique).

NE PAS RENOMMER les fichiers index.html, style.css, app.js, manifest.webmanifest et service-worker.js.
